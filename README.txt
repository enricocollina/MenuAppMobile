# Menu Settimanale

## Uso immediato
Apri `index.html` con un browser moderno.

## Per usarla come app su iPhone
La PWA deve essere servita tramite HTTP/HTTPS. Puoi pubblicare l'intera cartella su qualsiasi hosting statico.
Una volta aperta con Safari: Condividi -> Aggiungi a Home.

## Dati
Questa versione salva i dati nel browser (localStorage). Non richiede database né registrazione.
